Acker Spurführung V4.1 – Cache-Fix

Diese Version entfernt beim Start alte Service-Worker-Registrierungen und Browser-Caches,
damit nicht mehr die frühere PRO-Version geladen wird.

Installation:
1. In GitHub die vorhandene index.html durch diese index.html ersetzen.
2. Commit speichern.
3. Danach die Seite in Safari neu öffnen.
4. Oben muss 'Acker Spurführung V4.1' stehen.

Hinweis:
Die bestehende Funktionalität von V4 bleibt erhalten.
